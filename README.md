# yahoo_erase_feed_chrome

Yahoo!ニュースの[トピックス一覧](https://news.yahoo.co.jp/topics)で、記事ごとの配信メディア名を表示し、指定したメディアの記事をグレーアウトする Chrome 拡張（Manifest V3）です。

> **非公式・個人用です。** Yahoo! JAPAN とは関係ありません。Yahoo!ニュース側のページ構成が変わると、予告なく動かなくなることがあります。動作は保証しません。

## できること

- トピックス一覧（`/topics`、`/topics/domestic` などのカテゴリ別ページ）と、右カラムの「トピックス（主要）」で、各見出しの下にメディア名を表示する
- 指定したメディアの記事を半透明にして、「フィルタ中：メディア名」と表示する（記事は消さないので、クリックすれば読めます）
- フィルタするメディアは、ツールバーの拡張アイコンから開く popup で編集する

## インストール

1. このリポジトリを clone するか、ZIP でダウンロードして展開する
2. Chrome で `chrome://extensions` を開き、右上の「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」で、このフォルダを選ぶ

パッケージ化されていない拡張は Chrome の同期では配られないため、使いたい PC ごとにこの手順で読み込んでください。

`manifest.json` に `key` を入れて拡張 ID を固定しているので、どの PC のどのフォルダから読み込んでも ID は `bkaflnmmbbgnokiklkbcngebglmbhjjj` になります。

## 使い方

- トピックス一覧を開くと、見出しの下にメディア名が表示されます
- 拡張アイコンをクリックすると popup が開きます。フィルタしたいメディア名を 1 行に 1 つ書いて「保存」を押してください
  - メディア名は完全一致で判定します。表記ゆれを防ぐため、「最近見たメディア」の候補をクリックして追加するのがおすすめです
  - 保存すると、開いているページにもすぐ反映されます
- 初期設定では `AERA DIGITAL` がフィルタ対象になっています

## 仕組み

トピックス一覧のページには、メディア名が含まれていません。そこで、各トピックのリンク先（`/pickup/{id}`）を同じサイト内で取得し、次の順でメディア名を読み取ります。

1. `script[type="application/ld+json"]` の `author.name`
2. 1 で取れなかった場合は、`window.__PRELOADED_STATE__` の `topicsDetail.article.mediaName`

- 取得は同時 3 件までです。結果は `chrome.storage.local` にキャッシュするので、2 回目以降は新しく入ったトピックだけを取得します
- メディア名の表示とグレーアウトは CSS（`::after` と `:has()`）だけで行い、ページの DOM には手を加えません。判定済みの記事は、ページを開いた時点で反映されます
- フィルタ対象のリストは `chrome.storage.sync` に保存します。Chrome の同期がオンなら、同じ Google アカウントの他の PC にも引き継がれます（拡張 ID を固定しているので、各 PC で読み込むだけで共有されます）。キャッシュ（`storage.local`）は PC ごとです
- 必要な権限は `storage` だけです（`host_permissions` は使いません）

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `manifest.json` | 拡張の定義 |
| `content.js` | メディア名の取得・キャッシュと、表示・グレーアウト |
| `popup.html` / `popup.js` | フィルタ対象メディアの編集画面 |
